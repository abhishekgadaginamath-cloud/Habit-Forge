## PHASE 2 — GAMIFICATION LOGIC (server/utils/gamification.js)

Implement and export these pure functions:

### Streak calculation
```js
// Call this every time a habit is marked complete
function calculateStreak(lastCompletedDate, currentStreak) {
  const today = startOfDay(new Date());
  const last = lastCompletedDate ? startOfDay(new Date(lastCompletedDate)) : null;

  if (!last) return 1; // first time
  const diffDays = differenceInCalendarDays(today, last);

  if (diffDays === 1) return currentStreak + 1; // consecutive day
  if (diffDays === 0) return currentStreak;     // already done today
  return 1; // streak broken — reset to 1 (they just completed it)
}
```

### XP award
```js
function calculateXP(streak) {
  // Base 10 XP + 2 bonus per streak day (capped at 50 bonus)
  return 10 + Math.min(streak * 2, 50);
}
```

### Level from XP
```js
function calculateLevel(totalXP) {
  return Math.floor(Math.sqrt(totalXP / 50)) + 1;
}
```

### Badge checker (call after every habit completion)
```js
function checkBadges(user, streak, totalHabitsCompleted) {
  const newBadges = [];
  const existing = user.badges.map(b => b.name);

  const rules = [
    { name: 'First Step',      condition: totalHabitsCompleted >= 1 },
    { name: 'Consistency King', condition: streak >= 7 },
    { name: 'Habit Machine',   condition: streak >= 30 },
    { name: 'Century Club',    condition: totalHabitsCompleted >= 100 },
    { name: 'Level 5 Legend',  condition: calculateLevel(user.xp) >= 5 },
  ];

  for (const rule of rules) {
    if (rule.condition && !existing.includes(rule.name)) {
      newBadges.push({ name: rule.name, unlockedAt: new Date() });
    }
  }
  return newBadges;
}
```

## PHASE 3 — BACKEND API ROUTES

### Auth routes (/api/auth)
- POST /register — hash password with bcrypt, return JWT
- POST /login — verify password, return JWT
- Middleware: protect routes with JWT verification

### Habit routes (/api/habits) — all protected
- GET / — get all habits for logged-in user
- POST / — create habit (name, icon, color, frequency)
- PUT /:id/complete — mark habit complete for today:
  1. Call calculateStreak()
  2. Call calculateXP(streak)
  3. Save a Log document
  4. Update habit (streak, lastCompletedDate)
  5. Update user (xp, level via calculateLevel, add new badges)
  6. Return updated habit + any newly unlocked badges
- DELETE /:id — delete habit

### User/profile routes (/api/user)
- GET /profile — return user with xp, level, badges
- GET /stats — return: total habits, total logs, current streaks

### Analytics routes (/api/analytics) — premium gated
- GET /heatmap — return log counts grouped by date (last 365 days)
- GET /consistency — return daily completion % for last 30 days

## TIMEZONE HANDLING

All date comparisons use `date-fns/startOfDay` to normalize to midnight local time. Store all dates as UTC in MongoDB. The `calculateStreak` function always compares `startOfDay(new Date())` vs `startOfDay(lastCompletedDate)` so timezone drift doesn't cause false streak resets.
